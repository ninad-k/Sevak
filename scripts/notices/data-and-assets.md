## Bundled data and design assets

Material that is part of the repository rather than a dependency. Each section
says where it lives and what licence covers it.

### WordNet 3.0 (the bundled dictionary)

`crates/sevak-plugins/data/wordnet-en.z` is a trimmed copy of Princeton
University's WordNet 3.0 database: single words only, at most three meanings per
part of speech, definitions shortened and usage examples removed, plus WordNet's
lists of irregular word forms. It is generated by `scripts/build-dictionary.py`
and used offline by the `define` and `spell` keywords on systems without their
own dictionary.

### Unicode emoji data and CLDR annotations (the emoji picker)

`crates/sevak-plugins/data/emoji.tsv` lists emoji with their names and search
keywords. It is generated by `scripts/generate-emoji.mjs` from two Unicode Inc.
data sets and used offline by the `emoji` keyword:

- **Names and order** from `emoji-test.txt`, Unicode Emoji 15.1 (2023). The data
  file carries the notice "© 2023 Unicode®, Inc." and points to Unicode's Terms
  of Use.
- **Keywords** from the English annotations of the Unicode CLDR (Common Locale
  Data Repository), release 46 (`cldr-annotations-full@46`), distributed under
  the Unicode License v3.

Only fully-qualified emoji without skin-tone variants are kept, and each emoji is
reduced to one line, so the file is a modified copy. Unicode's permission notice
is the same for both and reads as follows. Unicode and the Unicode Logo are
registered trademarks of Unicode, Inc.

### Fonts, icons and artwork

- **Fonts:** none are bundled. The interface uses each operating system's own UI
  font.
- **Interface icons:** the result and settings glyphs are drawn in this
  repository as inline SVG; no third-party icon set is included.
- **Application icon and logo** (`assets/`, `ui/public/`, `src-tauri/icons/`):
  created for Sevak and licensed with it.
- **Brand names** in the documentation (for example Alfred, 1Password, Google,

  see the notes in [the plugin guide](docs/plugins.md#alfred-script-filter-scripts)
