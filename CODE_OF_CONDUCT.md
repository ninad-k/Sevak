# Code of Conduct

Sevak follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, patient and respectful. Disagree about ideas, not
people. Harassment, insults, discriminatory language, sexualised content and
publishing other people's private information are not acceptable, in the
issue tracker, pull requests or anywhere you represent the project.

## Reporting

If someone's behaviour makes you uncomfortable, contact the maintainer,
[@ninad-k](https://github.com/ninad-k), privately (contact details are on that
GitHub profile). Reports are handled confidentially.

## Enforcement

The maintainer may edit or remove comments, commits and other contributions
that break this code, and may temporarily or permanently ban a contributor,
following the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
