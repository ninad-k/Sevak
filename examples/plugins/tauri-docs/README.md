# Tauri docs for Sevak

Requires Node.js 22+ on PATH. Install this folder as a script plugin, reload
Sevak, and allow its Node command when prompted.

- `tauri updater`: open the updater guide.
- `tauri rust`: find Rust/IPC guides.
- `tauri global shortcut`: find the shortcut plugin.
- `tauri `: browse the curated guide list.

Titles, paths and keyword tags are searched locally; all words must match.
Enter opens an official `https://v2.tauri.app/` page. This is a curated link
index, not full-text search or a downloaded copy of the documentation.
No background requests or user data storage. Update `docs.mjs` when official
guide paths change. The browser needs internet access to load the pages.
